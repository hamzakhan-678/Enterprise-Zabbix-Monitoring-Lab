# Enterprise-Zabbix-Monitoring-Lab
Enterprise Infrastructure &amp; NOC Monitoring Lab using Zabbix on Ubuntu Linux Server. Configured Agent-based (ZBX) monitoring for Windows Server (AD, DNS, DHCP, IIS, SQL), Agentless SNMPv2 telemetry for pfSense Firewall, multi-step HTTP host-header web checks, and live incident auto-recovery testing.
